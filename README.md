# 柔性电路戒指原型

7月底，我参加了DIIS的未来首饰工作坊。从完全不懂硬件，到手拿电烙铁焊接戒指，再看到戒指按照我用AI辅助编程设计的程序闪灯发光，我发现：我，确实，可以，做出一个东西出来。这也让我意识到，在AI时代，以前所强调的那些专业背景、工作经验，都将重新被定义，更重要的是有没有把想法落地的愿力。

最近参加朋友摆摊的市集的时候，我聊起自己的日常穿搭，突然发现首饰可能是一个很适合我的入口。现在的AI以及打印技术也让我可以更快尝试设计和打样。muShenzhen Garage刚好在这个时候出现，我很期待借助深圳的硬件、工程和供应链环境，把塔罗元素、现代科技和身心觉察相结合，做出一件好玩的可穿戴首饰。
